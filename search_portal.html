배포 · 파일 연동 가이드

포탈 공유 방법과 PDF·논문 파일 연결하는 방법

📁 구글 드라이브로 PDF 파일 연결하기 (핵심 기능!)

논문 PDF, 엑셀, 한글, 워드 파일을 포탈에서 바로 열 수 있어요. 무제한 용량, 어디서든 접근 가능!

1
구글 드라이브 접속 — drive.google.com 접속 → 구글 계정으로 로그인 (구글 계정 없으면 무료 가입)
2
PDF 파일 올리기 — 드라이브 화면에 PDF 파일을 드래그앤드롭하거나, + 새로 만들기 → 파일 업로드 클릭
3
공유 링크 복사 — 업로드된 파일 우클릭 → 공유 → 상단에서 "링크가 있는 모든 사용자" 선택 → 링크 복사 클릭
4
포탈에 붙여넣기 — 논문 추가 모달에서 "구글 드라이브 링크" 칸에 붙여넣기 → 저장 후 파일 아이콘 클릭하면 PDF가 바로 열려요!
💡 더 편리하게 쓰는 팁
📂 폴더 통째로 연결 — 드라이브에 "압밀 논문" 폴더를 만들고 → 폴더 우클릭 → 공유링크 복사 → 포탈에 저장하면 폴더 전체가 연결됩니다
📱 스마트폰에서도 가능 — 구글 드라이브 앱에서 업로드하면 포탈에서 바로 열려요
🔗 링크 하나로 어디서든 — 집에서도, 학교에서도, 스마트폰에서도 같은 링크로 접근 가능
