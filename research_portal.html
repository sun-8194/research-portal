GitHub Pages 배포 가이드

이 포탈을 온라인에 올려서 링크로 공유하는 방법

⏱️ 총 소요 시간: 약 10분 · 비용: 완전 무료

1
GitHub 가입 — github.com 에서 무료 계정 만들기
2
새 저장소 만들기 — + → New repository → 이름: research-portal → Public → Create
3
파일 업로드 — Add file → Upload files → index.html 드래그 → Commit changes
4
Pages 활성화 — Settings → Pages → Branch: main → Save
5
링크 확인 — 1~2분 후 https://내아이디.github.io/research-portal 접속 가능!

📁 파일 연결 방법 (구글 드라이브)

1
구글 드라이브에 파일 업로드
2
파일 우클릭 → 공유 → 링크 복사 (링크 있는 모든 사용자)
3
논문/학습자료 추가 시 연결 파일 링크 칸에 붙여넣기
